## Project

Arcade Vault — a platform to play games online and compete for the highest score (per README.md, in Spanish). Currently a fresh, unmodified `create-next-app` scaffold: only the default starter page exists in `app/`, no game logic yet.

No test runner is configured yet.

## Stack

- Next.js 16.3.0 (App Router) — **do not assume familiar Next.js behavior**; see below.
- React 19.2.8, TypeScript (strict mode), Tailwind CSS v4 (via `@tailwindcss/postcss`, no `tailwind.config`)
- Path alias: `@/*` → repo root (`tsconfig.json`)

## Critical: read framework docs before coding

This repo pins a Next.js version newer than most training data and explicitly warns that APIs/conventions/file structure may differ from what you expect (see `AGENTS.md`). Before writing or modifying any Next.js code (routing, layouts, data fetching, config), check the bundled docs at `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`) for the relevant guide and any deprecation notices — do not rely on memorized Next.js conventions.

The `AGENTS.md` warning block at the top of that file is regenerated by `next dev` on every run (see `node_modules/next/dist/server/lib/generate-agent-files.js`). If it shows up as a diff, just commit it along with your other changes rather than removing it.
